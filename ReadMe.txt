Allereerst willen we zeggen dat we dit project met veel plezier hebben gemaakt maar voordat jullie de site 
gaan bekijken willen we jullie nog even wijzen op wat nodig is om de site via de localhost te laten werken.

Zorg ervoor dat bootstrap is geinstalleerd is op jouw python omgeving. Dit kan je doen door het volgende
commando in te voeren in de terminal: 

pip install django-bootstrap-v5

Dit is de enige requirement die je nodig hebt om de site te laten werken.
Typ het volgende commando in de terminal om de site te starten:

python manage.py runserver

Veel plezier met het ontdekken van onze site!
